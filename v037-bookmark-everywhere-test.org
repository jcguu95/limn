* ★ 最快路徑：互動 walkthrough（推薦）

如果你只想以最少時間看「整個 bookmark 系統運作給我看」、不想跑
shell 指令一條一條對 output，就跑這個：

#+begin_src bash

#+end_src

一條指令啟動 → 自動 ulimit / nix / 找 binary（缺就 build）/ spawn
Limn / connect。然後進入互動 walkthrough，14 步。每一步：

1. 印出 *將要 eval 的 Lisp form*
2. 印出 *預期看到什麼*
3. ~[SPC] + ENTER~ 注入並執行（~[s]~ skip / ~[q]~ quit early）
4. 印出 *實際結果*
5. ~[y] + ENTER~ match / ~[n] + ENTER~ not match / ~[s]~ unsure

結尾印 *copy-paste 友善* 的 summary 區塊（含 ~[✓] [✗] [·]~ 標記）。

涵蓋的 14 步驟：
| # | scope | 預期 |
|---+-------+------|
| 1 | package loaded | ~T~ |
| 2 | handlers (text/org/pdf) installed | ~T~ |
| 3 | open fixture PDF via mupdf | buffer-id string |
| 4 | view/set page 2 | wire ok |
| 5 | default-pdf-record | (:path ... :page 2 :y-offset ...) |
| 6 | wander to page 0 | wire ok |
| 7 | default-pdf-jump on saved record | ~T~ |
| 8 | view/get :page | ~2~（跳回原頁） |
| 9 | find-file tmp text | fbuf-id |
| 10 | buffer/cursor-set 11 | wire ok |
| 11 | default-text-record | (:file ... :position 11) |
| 12 | default-text-jump to position 0 | ~0~（cursor 移回） |
| 13 | save + clear + load CJK name | bookmark struct (:name "第一章 🌟") |
| 14 | M-x bookmark-set 'foo (mock minibuffer) | bookmark struct (:name "foo") |

* Cheat sheet：失敗對照表

| 症狀 | 出在哪 | 處理 |
|------+--------+------|
| ~Too many open files~ in PROCESS-* / COND-* | shell ~ulimit -n~ 太低（macOS 預設 256） | 走 1.1 BOOKMARK-only；或 ~ulimit -n 8192~ 後再跑 1.2 |
| ~V027-*~ 4 條 fail | 你 sprint 前的 pre-existing baseline | 跟 bookmark 無關、忽略 |
| 1.1 行數 < 35 | ASDF / load 早期就掛 | 回 0.x；或讀 ~run-unit.lisp~ stderr 找首條 error |
| 1.1 任何 ~BOOKMARK-*~ fail | 真的踩到我的 code | 抄條目給我 |
| Test B socket timeout | binary 啟動 crash | ~cat /tmp/limn-os-v037bm.log~ |
| ~Limn binary not found~ | LIMN_BIN env | 用 fallback 指令明示 LIMN_BIN |
| Test D ~C-x r b~ 沒反應 | pdf-mode prefix 攔 | 改 ~M-x bookmark-jump~ |
| Test D 視窗沒開 | binary path 錯 / nix 未進殼 | Ctrl-C → 明示 LIMN_BIN 重跑 |
| 4.7 SHA 不同 | trap 沒跑到 | ~mv ~/.limn/bookmarks.lisp.smoke-stash-* ~/.limn/bookmarks.lisp~ |
| 任何位置 stash 殘留 | trap 被強殺 | 同上 mv |
