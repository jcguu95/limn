#+TITLE: limn ROADMAP — 全 feature 總索引
#+STARTUP: overview

本檔是**所有 feature 的單一總索引**：有哪些功能線、各自做到哪、設計文件
在哪、ship 了沒。它**只列一行摘要 + 連結**，不展開細節——每個 feature 的
roadmap / sub-roadmap / 進度 checklist 住在它**自己的 design doc** 裡。

* 規則（先讀，跟版本制度同一套精神）

見 =versioning-policy.md=。三句話：

1. *integrator-only*：本索引**只在 merge 進 main 那一刻、由整合者更新**。
   feature 分支**永不碰本檔** → 永遠不會有多 agent 撞 merge（跟 CHANGELOG
   / 版本號發放同一個序列化點）。
2. *狀態分層，各信各的權威*：
   - 「已 ship」的真相 = =git tag= / =VERSION= / =CHANGELOG.org=，不在這裡
     重述，只引用其 =vX.Y.Z=。
   - 「進行中 / 計劃」的細節 = 該 feature 自己的 =docs/<feature>-design.md=
     裡的分階段 + =[x]/[ ]= checklist。本索引只標一個粗狀態。
3. *新 feature 怎麼進場*：開一份 =docs/<slug>-design.md=（範本見
   =split-frame-design.md=：目標 + 分階段 sub-roadmap + 活的 checklist），
   然後在本索引加**一行**指過去。**不要**在本檔展開細節、**不要**自封版本號。

狀態值：=planned= ⏭ ／ =in-progress= 🛠 ／ =shipped= ✅（附 tag）／
=blocked= ⛔（附 blocked-by）。

- 新 roadmap 下的重整：
  - Phase 5（=C-x= 視窗鍵位）**被取代** → 移交 leader-keys 的 =SPC w= namespace。

  - Phase 6（win-undo tree）⏭ planned,前置＝3c 先合。

* 計劃中 / 未排（planned）

** Fuzzy Selector（minad Vertico+Orderless 等價）  ⏭ planned ★第一優先
- 設計：=docs/completion-ui-design.md=（P1 章節）
- 把現有 =completing-read= 升級成垂直、即時、模糊比對的選單。是 minad 整套
  生態（Vertico/Orderless/Consult/Marginalia/Corfu/Cape/Embark/Tempel）的
  **第一塊**;其餘 P2–P4 先記在該 doc、deferred。
- 槓桿大：leader 樹每個葉子幾乎都叫 completing-read,一次升級全面受益。
  零件多已存在（v0.25 completing-read、v0.28 which-key 渲染、vendored fzf）。

** evil（vim 模態編輯）  ⏭ planned（leader 的前置依賴）
- 設計：=docs/evil-mode-design.md=
- normal↔insert state + vim motion/operator。**Doom 體感的根基**,也是 =SPC=
  leader 的前提（normal 下 =SPC=leader、insert 下 =SPC=空白）。先行於 leader。
- pdf-mode 既有 vim 式 j/k 收編成 evil normal 的特化,消除雙模態。

** Doom =SPC= leader 鍵位（預設方案 + 全 agent policy）  ⏭ planned
- 設計：=docs/leader-keys-design.md=
- 把 Doom 風 namespaced =SPC= leader（配 which-key）做成 limn **預設**鍵位;
  純 Emacs 使用者用 config 開關退回 =C-x=/=C-c= 自綁。**同時是 policy**：
  以後所有 feature 預設綁定走 =SPC= 樹（已寫進 =CLAUDE.md=,全 agent follow）。
- §0 已定案 ✅：evil 模態必要;normal=`SPC`、insert=`M-SPC`（依賴 evil 先行）。

** PDF hyperlink（internal / external）  ⏭ planned
- 設計：=docs/pdf-hyperlink-design.md=
- 偵測 / 顯示 / 點擊跳轉 PDF 連結。internal=文件內 GoTo（複用 win-focus/
  bookmark 還原視角）、external=URL/mailto 走受控 =os/open=。大半靠 MuPDF
  原生 =fz_load_links=,零件多已存在。

** cursor 外觀（cursor alternating size）  ⏭ planned
- 設計：=docs/cursor-style-design.md=
- 文字游標交替大小（比 blink 更好定位）+ 把游標樣式做成後端可配置（對齊
  Emacs =cursor-type=/=blink-cursor-mode=）。純視覺,靠 walkthrough 驗證。

** Lisp runtime 深水區roadmap  ⏭ planned
- 索引不重複展開——權威清單在 =LIMN-SPEC.org= §12（Edit Model、Markers、
  Syntax tables、Current buffer、視覺系統 overlays :face、cl-ppcre regex、
  file-notify、query-replace…）。注意 §12 那些 =v0.NN ⏭ planned= 號碼是
  **制度生效前的非權威佔位標籤**（見該節開頭聲明），真正版本號 merge 時才發。
