* Limn 測試套件

完整覆蓋 Limn spec 的測試集，全部用 Common Lisp 寫成。

測試分兩類：

** 整合測試（=suites/=）

這類測試會透過 Unix socket 接到一個正在跑的 Limn process，演練 bridge
protocol。執行前 Limn 必須先以 =--headless --socket /tmp/limn-test= 起來。

| Suite              | 涵蓋範圍                                                |
|--------------------+---------------------------------------------------------|
| =smoke.lisp=       | 基本健全性：可連線、fixture 存在                        |
| =protocol.lisp=    | Wire 協議：id、response 結構、錯誤處理                  |
| =bridge.lisp=      | =bridge/= namespace：windows、frames、engine-load       |
| =view.lisp=        | =view/set= 和 =view/get=（通用 viewport 操作）          |
| =overlays.lisp=    | =view/overlays=（rect/line/text 繪製基本元件）          |
| =buffer.lisp=      | =buffer/= namespace：內容抽取與渲染                     |
| =events.lisp=      | Frontend → Backend 推送事件                             |
| =engine-spec.lisp= | Engine Interface Spec 合規性                            |
| =mupdf-engine.lisp=| mupdf 專屬行為（dark-mode、rotation、PDF）              |
| =integration.lisp= | 多步驟流程（search+highlight、portal、undo）            |
| =stress.lisp=      | 大量請求、超大 payload、畸形輸入                        |

** 單元測試（=unit/=）

純 Lisp 測試，不需要 Limn 在跑。專門測 =backend/= 內各模組的 API 契約。

| Suite                    | 涵蓋範圍                                        |
|--------------------------+-------------------------------------------------|
| =bridge-client.lisp=     | =limn/bridge= — JSON encode/decode、request 處理 |
| =keymap.lisp=            | =limn/keys= — Emacs 風格的 keymap               |
| =undo.lisp=              | =limn/undo= — 含分支的 undo tree                |
| =hooks.lisp=             | =limn/hooks= — 事件 hook registry               |
| =buffer-registry.lisp=   | =limn/buffer= — Lisp 端的 buffer 追蹤           |
| =search.lisp=            | =limn/search= — 搜尋邏輯（用 fake 資料測試）    |

** 執行方式

整合測試（需要 Limn 在跑）：

#+begin_src bash
./backend/tests/run-tests.sh
#+end_src

單元測試（純 Lisp）：

#+begin_src bash
sbcl --script backend/tests/unit/run-unit.lisp
#+end_src

** 環境變數

| =LIMN_SOCKET=  | Socket 路徑（預設 =/tmp/limn-test=）                |
| =LIMN_FIXTURE= | PDF fixture（預設 =backend/tests/fixtures/test.pdf=）|
| =LIMN_VERBOSE= | 有設就會把每個 wire 訊息全部 log 出來               |

** Fixtures

把測試用 PDF 放到 =backend/tests/fixtures/test.pdf=。詳細選項看該目錄
下的 README。

** 目前狀態
