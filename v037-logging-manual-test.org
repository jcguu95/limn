* 6. Manual REPL — Verbosity 同時 filter wire 跟 event（核心 invariant）

這是最重要的一個 case：**ring 永遠記錄、wire/event 受 level filter、
兩者 single source 是 Lisp ring**。接續同一個 REPL。

- [ ] *Step 6.1*：清空 ring + 設一個高門檻 ns：
  #+BEGIN_SRC lisp
(limn/log:clear-messages)
(limn/log:set-level 'noisy :error)
  #+END_SRC
  - *預期*：第一行 =NIL=，第二行 =:ERROR=

- [ ] *Step 6.2*：發一個 :info 訊息（被 filter 掉）：
  #+BEGIN_SRC lisp
(limn/log:message :level :info :ns 'noisy "should-be-filtered")
  #+END_SRC
  - *預期*：return 字串 ="should-be-filtered"=

- [ ] *Step 6.3*：確認 ring **有**記錄（不看 level）：
  #+BEGIN_SRC lisp
(limn/log:get-messages 5)
  #+END_SRC
  - *預期*：list 第一個元素就是 ="should-be-filtered"=
  - *不預期*：list 為空 / 沒這條（表示 ring 也被 filter 了，違反 invariant）

- [ ] *Step 6.4*：確認 wire 端 (C++ GapBuffer) **沒**收到：
  #+BEGIN_SRC lisp
(let ((txt (getf (getf (limn:call "buffer/text" :|buffer-id| "*messages*")
                       :|data|) :|text|)))
  (search "should-be-filtered" txt))
  #+END_SRC
  - *預期*：return =NIL=（GapBuffer 字串中找不到此 substring，表示 wire
    sender 被 effective-level 正確擋下）
  - *不預期*：return 一個整數（表示 wire sender 沒 filter、跟 spec 違背）

- [ ] *Step 6.5*：對照組 — :error 級訊息**有**進 wire：
  #+BEGIN_SRC lisp
(limn/log:message :level :error :ns 'noisy "should-be-shown")
(let ((txt (getf (getf (limn:call "buffer/text" :|buffer-id| "*messages*")
                       :|data|) :|text|)))
  (search "should-be-shown" txt))
  #+END_SRC
  - *預期*：return 一個整數（找到 substring 位置）
  - *不預期*：=NIL=（表示 :error 也被擋了，level 邏輯方向錯）

* 7. Manual REPL — Wire format prefix 完整驗證

接續同一個 REPL。

- [ ] *Step 7.1*：
  #+BEGIN_SRC lisp
(limn/log:clear-messages)
(limn/log:message :level :warn :ns 'my-test.sub "x=~A" 42)
(let ((r (limn:call "buffer/text" :|buffer-id| "*messages*")))
  (getf (getf r :|data|) :|text|))
  #+END_SRC
  - *預期*：return 字串符合以下 pattern（regex 心驗）：
    =\[\d{2}:\d{2}:\d{2} WARN  my-test\.sub\] x=42=
    具體例如 =[14:35:11 WARN  my-test.sub] x=42=
    重點：
    1. =[HH:MM:SS]= — 兩位數時/分/秒
    2. =WARN ⎵= — level 後面 padding 一個空格（對齊 5 字元）
    3. =my-test.sub= — symbol-name 轉成 lowercase + 保留 dot
    4. =x=42= — format 正確展開（不是 ="x=~A"= 跟 =42= 沒接上）
  - *不預期*：任何一條 prefix 部分缺失、ns 變大寫、format 沒展開
