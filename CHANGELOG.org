* v0.13.1 — windowkill cleanup（cumulative-state flake 殺到 0）
:PROPERTIES:
:DATE: 2026-05-23
:END:

v0.13 ship 時誠實標 mouse-extras 還有 ~25% intermittent flake、本來
推給「per-driver fresh Xvfb」infra 重寫。實測發現不用：root cause
是 driver process 死了、X window 卻沒馬上從 X server 消失（openbox
close handshake 有 hundreds-of-ms 延遲）。

修：=cleanup_between_drivers= 加 =xdotool windowkill= loop + poll
確認真消失。

驗證：4 連跑 33/33 全綠。

* v0.8.0 — Qt 版 Emacs 骨架成立
:PROPERTIES:
:DATE: 2026-05-22
:END:

第一個版本「使用者能透過 init.lisp 自訂 Limn 行為，不必改 framework
source code」。

核心新增：
- Mode keymap stack 真實 dispatch（minor → major → global，§9.1）
- =defcommand "s"= 真接 minibuffer round-trip（透過 bridge
  =minibuffer/open= + 等 =minibuffer-submit= 事件，§9.2）
- =keyboard-quit= command + global / minibuffer-mode keymap 綁 C-g
- Init file 自動載入（§9.3：=$LIMN_INIT= → =~/.limn/init.lisp= →
  =~/.config/limn/init.lisp=）
- Introspection (§9.4)：=describe-key= / =describe-command= /
  =where-is-command= / =list-modes=
- C++ buffer editing primitives（cursor / insert / delete）、真實 Qt
  window split、mouse coord → page mapping

第一份 demo init.lisp 含 vim-style 翻頁 + =/= minibuffer 搜尋。

* v0.1.0-baseline — Sioyek Core 抽出
:PROPERTIES:
:DATE: 2026-05-19
:END:

從 Sioyek 擷取最小可運行的 PDF 渲染核心。

移除所有上層（設定系統、鍵盤輸入、觸控 UI、SyncTeX），僅保留：MuPDF
